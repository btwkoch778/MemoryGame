# Memory Game

A simple memory game built with C# and Windows Forms.

- 8 cards and 4 color pairs.
- Each correct pair gives 1 point.
- Wrong guesses keep the score unchanged; both cards close after a short delay.
- ✅ for a match, ❌ for a wrong guess.
- The game ends when all 4 pairs are found.
- **Yeni oyun** starts a new shuffled game. **Çıxış** closes the app.

## Run

Windows, .NET 8 SDK and Visual Studio 2022 (17.8 or later) with the **.NET desktop development** workload are required.

Extract the ZIP, open `MemoryGame.sln` and press **F5**.

## Azərbaycanca

C# və Windows Forms ilə hazırlanmış yaddaş oyunu. 8 kartın arxasında 4 rəng cütü gizlənir. Eyni rəngli iki kartı açanda 1 xal qazanılır. Səhv seçimdə xal dəyişmir və kartlar 0,85 saniyədən sonra bağlanır. Bütün cütlər tapıldıqda oyun bitir. Maksimum xal: **4**.

ZIP-i çıxarın, Windows-da Visual Studio ilə `MemoryGame.sln` faylını açın və **F5** basın. **.NET desktop development** komponenti və **.NET 8 SDK** quraşdırılmış olmalıdır. Windows Forms macOS-da birbaşa işləmir.
